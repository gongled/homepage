# Дизайн: переработка homepage под позиционирование Technology Leader

Дата: 2026-07-26
Статус: утверждено пользователем

## Цель

Упаковать опыт кандидата для HR-служб ИТ-компаний в РФ (русская версия) и за рубежом (английская версия). Текущее позиционирование сайта («Unit Lead, SRE») устарело: с 2025 года — миграция Yandex.Cloud → Cloud.ru (~600 участников), с сентября 2025 — Lead Solution Architect и CTO-функции.

Целевые роли (все четыре): Lead/Principal Solution Architect, CTO/Head of IT, Engineering Manager/Unit Lead, консультант/advisory. Заголовок — универсальный («Technology Leader»), роли раскрываются как компетенции ниже.

Оба рынка равнозначны: EN-версия — адаптация под ожидания западных компаний, а не дословный перевод.

## Выбранный подход

Гибрид: главная = компактный профиль + отдельная страница «Резюме/CV» в HR-формате. Таймлайн карьеры, статьи и выступления сохраняются.

## Карта сайта (RU + EN зеркала)

```
/                      главная-профиль: hero-позиционирование, 4 метрики, ссылки на разделы
/cv/                   резюме в HR-формате (новая страница)
/work/career/          таймлайн карьеры (обновлённый контент, структура по ролям)
/work/buzzwords/       инструменты и технологии (обновить)
/public-speaking/, /articles/   без структурных изменений
```

`content/work*.md` переписывается под новое позиционирование и становится главной; блоки «Нанимателям/Рекрутерам» уходят в CV. В `config.toml` description: «Юнит лид в Купере» → универсальный заголовок.

## Ограничения (NDA)

- Нельзя: бизнес-эффекты/TCO самой миграции, точное количество кластеров, vCPU/RAM/Storage (даже порядки — по решению пользователя не указываем).
- «Стандарты банка» → «корпоративные стандарты» (нейтрализация привязки).
- Можно: сроки миграции (мар 2025 — мар 2026), число ИС/продуктов, ~600 участников, «в срок, без инцидентов».

## Стиль копирайтинга

- Минимализм; активный залог («сделал», не «было сделано»).
- Информационный стиль по Максиму Ильяхову и Норе Галь: без штампов и канцелярита, факты и цифры вместо оценок, польза для читателя (HR/нанимающего менеджера), короткие предложения.
- EN-версия: адаптация, не дословный перевод (cloud migration, enterprise architecture, TCO reduction, platform engineering).

## Техническая реализация

- Hugo (тема `themes/simple`, Tailwind-подобные классы в шаблонах).
- Новый layout `themes/simple/layouts/_default/cv.html` + `content/cv.md` и `content/cv.en.md` (front matter `layout: cv`).
- Данные CV (метрики, роли, экспертиза, DevRel) — в `data/translations/ru-RU.yaml` и `en-US.yaml` рядом с `career`, чтобы RU/EN не расходились; шаблон рендерит из data (как `career.html`).
- Главная: правка `content/work.md` / `content/work.en.md` + новый layout `landing.html` (наследует стили темы), который рендерит hero-заголовок и 4 метрики из data; минимальная вёрстка в стиле существующей темы.
- `data/tools.yaml` (buzzwords): добавить Cloud.ru, EA-практики (ADR, технологический радар, CMDB), AI-стек (MCP, LLMOps); при желании — почистить устаревшее.
- `config.toml`: description RU/EN → универсальный заголовок.
- Проверка: `hugo server` / сборка (`make` / npm-скрипты из package.json) без ошибок, визуальная проверка обеих локалей.

## Вне объёма

- Редизайн темы, новые цвета/шрифты.
- Изменение статей и выступлений.
- Форма обратной связи, аналитика.
